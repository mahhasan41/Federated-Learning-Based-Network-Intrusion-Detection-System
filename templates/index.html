ℹ️ About This System

Federated Learning NIDS is a privacy-preserving intrusion detection system that uses federated learning to train models across multiple distributed clients without centralizing sensitive network traffic data. The system leverages PyTorch for deep learning and implements the FedAvg algorithm for secure model aggregation.

Key Features: Multi-class attack classification, real-time predictions, client-wise evaluation, feature importance analysis, and comprehensive performance metrics including accuracy, precision, recall, and F1-score.
