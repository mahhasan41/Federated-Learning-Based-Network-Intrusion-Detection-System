## 🔐 PRIVACY FEATURES

This system demonstrates privacy-preserving machine learning through:

1. **No Raw Data Sharing**
   - Each client trains independently on local data
   - Only model weights communicated to server
   - Original network traffic data never leaves client devices

2. **Federated Aggregation**
   - Server aggregates weights from all clients
   - Uses FedAvg (weighted averaging) algorithm
   - No individual client updates visible to other clients

3. **Distributed Learning**
   - Model trained across multiple nodes
   - Each node maintains privacy of its data
   - Global model benefits from collective learning

4. **Comparison with Centralized Approach:**
   
   Centralized NIDS:
   ├── All traffic data stored centrally ❌
   ├── Single point of failure ⚠️

   └── Compliance issues ❌
   
   Federated NIDS (This Project):
   ├── Data stays distributed ✓

## 📚 TECHNICAL DETAILS

### Preprocessing Pipeline:
Raw Data → Missing Values → Encoding → Selection → Normalization → SMOTE → Ready

### Federated Training Loop:
1. Server broadcasts global model to clients
2. Each client trains locally for 5 epochs
3. Clients upload updated weights
4. Server aggregates using FedAvg
5. Server evaluates on test set
6. Repeat for 10 rounds

### Model Architecture:
Input (50) → Dense(256)+ReLU+DO → Dense(128)+ReLU+DO → Dense(64)+ReLU+DO → Output (6)

### FedAvg Algorithm:
W_global = Σ (|D_i| / |D|) * W_i
where |D_i| is client data size, W_i is client weights
